S1 // DATA OBSERVATORY

Statistical Foundations

A complete foundation in statistical sampling, data analysis, probability, discrete random variables and the binomial distribution.

TOPIC 01 // POPULATION SYSTEM

Statistical Sampling

Statistical investigations usually begin by collecting information from a population.

Population and Sample

The population is the complete set of individuals or objects being investigated. A sample is a smaller group selected from the population.

IMPORTANT // REPRESENTATION

A sample should be representative of the population if reliable conclusions are to be drawn.

Sampling Methods

  • Simple random sampling
  • Systematic sampling
  • Stratified sampling
  • Quota sampling

Bias

Bias occurs when a sampling method systematically favours certain members of the population.

TOPIC 02 // DATA VISUALISATION

Data Presentation and Interpretation

Data can be organised and represented in different ways to make important features easier to identify.

Frequency Tables

A frequency table records the number of observations belonging to each value or class.

Histograms

Histograms are used for continuous data. The area of each bar represents frequency.

FREQUENCY DENSITY
Frequency density = Frequency ÷ Class width

Cumulative Frequency

Cumulative frequency is the running total of frequencies. It can be used to estimate the median, quartiles and percentiles.

Box Plots

A box plot summarises data using the minimum, lower quartile, median, upper quartile and maximum.

TOPIC 03 // DATA METRICS

Measures of Location and Spread

Mean

Mean = Σx ÷ n

Median

The median is the middle observation when the data is arranged in ascending order.

Range

Range = Maximum − Minimum

Interquartile Range

IQR = Q₃ − Q₁

Variance

Var(X) = E(X²) − [E(X)]²

Standard Deviation

Standard deviation = √Variance

WORKED EXAMPLE // LOCATION

Find the mean of 4, 7, 9 and 12.

Mean = (4 + 7 + 9 + 12) ÷ 4

Mean = 32 ÷ 4

Mean = 8

TOPIC 04 // PROBABILITY FIELD

Probability

Probability describes how likely an event is to occur.

0 ≤ P(A) ≤ 1

Complement

P(A') = 1 − P(A)

Addition Rule

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Mutually Exclusive Events

P(A ∩ B) = 0

Independent Events

P(A ∩ B) = P(A)P(B)

TOPIC 05 // RANDOM VARIABLE ENGINE

Discrete Random Variables

A discrete random variable takes a countable set of possible numerical values.

PROBABILITY DISTRIBUTION

The probabilities of all possible values must add to 1.

ΣP(X = x) = 1

Expected Value

E(X) = ΣxP(X = x)

Variance

Var(X) = E(X²) − [E(X)]²

TOPIC 06 // BINOMIAL ENGINE

Binomial Distribution

The binomial distribution models the number of successes obtained in a fixed number of independent trials.

X ~ B(n, p)

Conditions

  • A fixed number of trials.
  • Each trial has two possible outcomes.
  • The probability of success remains constant.
  • The trials are independent.

Probability Formula

P(X = r) = ⁿCᵣ pʳ(1 − p)ⁿ⁻ʳ

Mean

E(X) = np

Variance

Var(X) = np(1 − p)

TOPIC 07 // RELATIONSHIP NETWORK

Correlation and Regression

Correlation describes the strength and direction of a linear relationship between two variables.

Types of Correlation

  • Positive correlation
  • Negative correlation
  • No correlation

Product Moment Correlation Coefficient

The product moment correlation coefficient measures the strength of linear correlation.

RANGE

The correlation coefficient lies between −1 and 1.

Regression Line

A regression line provides a mathematical model for the relationship between two variables and can be used to make predictions.

y = a + bx
REMEMBER

Correlation does not necessarily imply causation.

PRACTICE // S1 DATA TRIALS

S1 Mixed Practice

1. Explain the difference between a population and a sample.
SHOW ANSWER

A population is the complete group being studied, while a sample is a subset selected from that population.

2. State one advantage of simple random sampling.
SHOW ANSWER

Every member of the population has an equal chance of being selected.

3. Find the mean of 6, 8, 10, 11 and 15.
SHOW ANSWER

Mean = (6 + 8 + 10 + 11 + 15) ÷ 5 = 10.

4. If P(A) = 0.27, find P(A').
SHOW ANSWER

P(A') = 1 − 0.27 = 0.73.

5. A random variable X has probabilities that must sum to what value?
SHOW ANSWER

The probabilities must sum to 1.

6. State the four conditions required for a binomial model.
SHOW ANSWER

Fixed number of trials, two possible outcomes, constant probability of success and independent trials.

7. What is the possible range of the product moment correlation coefficient?
SHOW ANSWER

−1 ≤ r ≤ 1.

8. For X ~ B(10, 0.3), find E(X).
SHOW ANSWER

E(X) = np = 10 × 0.3 = 3.
