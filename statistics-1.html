Statistics 1

Build a strong foundation in statistics through data, probability, distributions, correlation and regression.

TOPIC 01

Data Collection

Statistics begins with collecting reliable data. The method used to collect data can strongly affect the conclusions that can be drawn.

Population and Sample

A population is the complete group being studied. A sample is a smaller group selected from the population.

Key idea:

A good sample should be representative of the population.

Types of Data

  • Primary data — collected directly for a particular investigation.
  • Secondary data — obtained from an existing source.
  • Discrete data — values that can be counted.
  • Continuous data — values measured on a continuous scale.

TOPIC 02

Sampling Methods

Sampling methods determine how individuals are selected from a population.

Simple Random Sampling

Every member of the population has an equal chance of being selected.

Systematic Sampling

Individuals are selected at regular intervals from an ordered population.

Stratified Sampling

The population is divided into groups called strata. A sample is then taken from each stratum in proportion to its size.

Quota Sampling

A fixed number of individuals are selected from different categories until the required quota is reached.

TOPIC 03

Data Presentation

Data can be represented using tables and diagrams to make patterns easier to identify.

Common Representations

  • Frequency tables
  • Bar charts
  • Histograms
  • Cumulative frequency diagrams
  • Box plots
Important:

Histograms are used for continuous data and their areas represent frequency.

TOPIC 04

Measures of Location and Spread

Mean

The mean is found by adding all observations and dividing by the number of observations.

Mean = Σx / n

Median

The median is the middle value when the observations are arranged in order.

Range

Range = Maximum − Minimum

Interquartile Range

IQR = Q₃ − Q₁

TOPIC 05

Probability

Probability measures how likely an event is to occur.

0 ≤ P(A) ≤ 1

Complementary Events

P(A') = 1 − P(A)

Addition Rule

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

Independent Events

P(A ∩ B) = P(A)P(B)

TOPIC 06

Discrete Probability Distributions

A discrete random variable takes a countable set of possible values.

Probability distribution:

The probabilities of all possible values must add to 1.

ΣP(X = x) = 1

Expected Value

E(X) = ΣxP(X = x)

TOPIC 07

Binomial Distribution

The binomial distribution can be used when there are a fixed number of independent trials, each with two possible outcomes.

P(X = r) = ⁿCᵣ pʳ(1 − p)ⁿ⁻ʳ

Conditions

  • Fixed number of trials.
  • Each trial has two possible outcomes.
  • The probability of success remains constant.
  • The trials are independent.

TOPIC 08

Correlation and Regression

Correlation describes the strength and direction of a linear relationship between two variables.

Correlation

A scatter diagram can be used to investigate correlation.

  • Positive correlation
  • Negative correlation
  • No correlation

Regression

A regression line can be used to model the relationship between two variables and make predictions.

PRACTICE

S1 Mixed Practice

1. Explain the difference between a population and a sample.
Show answer

A population is the complete group being studied, while a sample is a subset selected from that population.

2. Find the mean of 4, 7, 8, 11 and 15.
Show answer

Mean = (4 + 7 + 8 + 11 + 15) / 5 = 9.

3. If P(A) = 0.35, find P(A').
Show answer

P(A') = 1 − 0.35 = 0.65.

4. State the conditions required for a binomial model.
Show answer

There must be a fixed number of independent trials, two possible outcomes on each trial, and a constant probability of success.

5. What does positive correlation mean?
Show answer

As one variable increases, the other variable tends to increase.
