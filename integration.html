Pure Mathematics

Integration

Edexcel International A Level Mathematics

1. What Is Integration?

Integration is the reverse process of differentiation.

If differentiation gives the gradient of a function, integration can be used to recover the original function.

∫ f(x) dx

The symbol ∫ represents integration, while dx indicates that the integration is performed with respect to x.

2. The Power Rule for Integration

For powers of x, increase the power by 1 and divide by the new power.

∫ xⁿ dx = xⁿ⁺¹ / (n + 1) + C

This rule applies when n ≠ −1.

C is the constant of integration.

Worked Example

Integrate:

∫ x³ dx
= x⁴ / 4 + C
∫ x³ dx = x⁴ / 4 + C

3. Integrating Polynomial Functions

Polynomial expressions can be integrated term by term.

Worked Example

Integrate:

∫ (6x² + 4x − 5) dx
= 2x³ + 2x² − 5x + C
Answer: 2x³ + 2x² − 5x + C

4. Negative and Fractional Powers

Roots and fractions can be rewritten using indices before integration.

√x = x¹ᐟ²
1/x² = x⁻²

Worked Example

Integrate:

∫ √x dx
= ∫ x¹ᐟ² dx
= x³ᐟ² / (3/2) + C
= 2/3 x³ᐟ² + C

5. Integrating 1/x

The normal power rule cannot be used when the power is −1.

∫ 1/x dx = ln|x| + C

Worked Example

Integrate:

∫ 5/x dx
= 5ln|x| + C

6. Definite Integration

A definite integral has an upper and lower limit.

∫ₐᵇ f(x) dx

Find an antiderivative and then substitute the upper and lower limits.

∫ₐᵇ f(x) dx = F(b) − F(a)

Worked Example

Evaluate:

∫₀² x² dx
∫ x² dx = x³ / 3
[x³ / 3]₀²
= 8/3 − 0
= 8/3

7. Area Under a Curve

A definite integral can be used to find the area between a curve and the x-axis when the curve remains above the axis.

Area = ∫ₐᵇ y dx

Worked Example

Find the area under y = x² from x = 0 to x = 3.

Area = ∫₀³ x² dx
= [x³ / 3]₀³
= 27/3
= 9

8. Area Between Two Curves

When one curve lies above another, subtract the lower curve from the upper curve.

Area = ∫ₐᵇ (upper curve − lower curve) dx

Worked Example

Find the area between:

y = x
y = x²

between x = 0 and x = 1.

Area = ∫₀¹ (x − x²) dx
= [x²/2 − x³/3]₀¹
= 1/2 − 1/3
= 1/6

9. The Constant of Integration

When integrating without limits, always include + C.

∫ 3x² dx = x³ + C

The constant is necessary because different functions can have the same derivative.

Example

dy/dx = 6x
y = 3x² + C

10. Finding the Constant Using a Condition

If a point on the curve is known, it can be used to determine the value of C.

Worked Example

Given:

dy/dx = 6x

and the curve passes through (2, 5), find y.

y = 3x² + C
5 = 3(2²) + C
5 = 12 + C
C = −7
y = 3x² − 7

⚠️ Common Mistakes

1. Forgetting + C

For indefinite integration, always include the constant of integration.

2. Dividing by the wrong number

Increase the power by 1, then divide by the new power.

x⁴ → x⁵/5

3. Using the power rule for 1/x

∫ 1/x dx = ln|x| + C

4. Reversing the limits

For a definite integral, use:

F(upper) − F(lower)

5. Confusing signed area with geometric area

If a curve passes below the x-axis, the integral may be negative. Total geometric area may require splitting the interval.

🎯 Exam Tips

1. Check whether limits are given

No limits normally means an indefinite integral, so + C is required.

2. Rewrite before integrating

Convert roots and fractions into powers where appropriate.

3. Differentiate your answer

Differentiating your result is a useful way to check an integration answer.

4. Keep exact values

Avoid unnecessary decimal approximations unless the question specifically requests them.

5. Identify the correct region

For the area between two curves, remember:

Upper − Lower
