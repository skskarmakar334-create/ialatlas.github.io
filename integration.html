Integration

Edexcel International A Level Mathematics

1. What Is Integration?

Integration is the reverse process of differentiation.

If differentiation gives the gradient of a function, integration can be used to recover the original function.

∫ f(x) dx

The symbol ∫ represents integration.

The expression dx indicates that we are integrating with respect to x.

2. The Power Rule for Integration

For powers of x:

∫ xⁿ dx = xⁿ⁺¹/(n + 1) + C

provided n ≠ −1.

C is the constant of integration.

Worked Example

Integrate:

∫ x³ dx
= x⁴/4 + C
∫ x³ dx = x⁴/4 + C

3. Integrating Polynomial Functions

Integrate each term separately.

Worked Example

Integrate:

∫ (6x² + 4x − 5) dx
= 2x³ + 2x² − 5x + C

Therefore:

2x³ + 2x² − 5x + C

4. Negative and Fractional Powers

Rewrite roots and fractions as powers before integrating.

√x = x¹ᐟ²
1/x² = x⁻²

Worked Example

Integrate:

∫ √x dx

Rewrite:

∫ x¹ᐟ² dx
= x³ᐟ²/(3/2) + C
= 2/3 x³ᐟ² + C

5. Integrating 1/x

The normal power rule cannot be used when n = −1.

Instead:

∫ 1/x dx = ln|x| + C

Worked Example

Integrate:

∫ 5/x dx
= 5ln|x| + C

6. Definite Integration

A definite integral has limits.

∫ᵃᵇ f(x) dx

To evaluate it, find an antiderivative and substitute the upper and lower limits.

∫ᵃᵇ f(x) dx = F(b) − F(a)

Worked Example

Evaluate:

∫₀² x² dx

First integrate:

∫ x² dx = x³/3

Apply the limits:

[x³/3]₀²
= 8/3 − 0
= 8/3

7. Area Under a Curve

A definite integral can be used to find the area between a curve and the x-axis over an interval where the function is non-negative.

Area = ∫ᵃᵇ y dx

Worked Example

Find the area under y = x² from x = 0 to x = 3.

Area = ∫₀³ x² dx
= [x³/3]₀³
= 27/3
= 9

8. Area Between Two Curves

When one curve lies above another:

Area = ∫ᵃᵇ (upper curve − lower curve) dx

Worked Example

Find the area between:

y = x
y = x²

between x = 0 and x = 1.

Area = ∫₀¹ (x − x²) dx
= [x²/2 − x³/3]₀¹
= 1/2 − 1/3
= 1/6

9. The Constant of Integration

When integrating without limits, always include + C.

∫ 3x² dx = x³ + C

The constant is required because many different functions have the same derivative.

Example

If:

dy/dx = 6x

then:

y = 3x² + C

10. Finding the Constant Using a Condition

Sometimes a point on the curve is given. This allows us to determine C.

Worked Example

Given:

dy/dx = 6x

and the curve passes through (2, 5), find y.

Integrate:

y = 3x² + C

Substitute (2, 5):

5 = 3(2²) + C
5 = 12 + C
C = −7
y = 3x² − 7

⚠️ Common Mistakes

1. Forgetting + C

For indefinite integration, always include the constant of integration.

2. Dividing by the wrong number

When integrating xⁿ, increase the power by 1 and divide by the new power.

x⁴ → x⁵/5

3. Using the power rule for 1/x

Remember:

∫ 1/x dx = ln|x| + C

4. Reversing upper and lower limits

For a definite integral:

F(upper) − F(lower)

5. Confusing area with signed area

If a curve goes below the x-axis, the definite integral can be negative. Finding total geometric area may require splitting the interval.

🎯 Exam Tips

1. Check whether limits are given

No limits usually means an indefinite integral and therefore + C is required.

2. Rewrite before integrating

Convert roots and fractions into powers where appropriate.

3. Differentiate your answer

A quick differentiation check can confirm whether your integration is correct.

4. Keep exact values

Avoid unnecessary decimal approximations.

5. For areas, identify the correct curve

When finding the area between two curves, use:

Upper − Lower
