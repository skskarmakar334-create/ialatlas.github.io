Trigonometry

Edexcel International A Level Mathematics

1. Basic Trigonometric Ratios

In a right-angled triangle, the three main trigonometric ratios are sine, cosine and tangent.

sin θ = opposite / hypotenuse
cos θ = adjacent / hypotenuse
tan θ = opposite / adjacent

A useful memory aid is:

SOH — CAH — TOA

Worked Example

A right-angled triangle has opposite side 6 and hypotenuse 10. Find θ.

sin θ = 6/10
sin θ = 0.6
θ = sin⁻¹(0.6)
θ ≈ 36.87°

2. Exact Trigonometric Values

You should know the exact values of the main trigonometric functions for common angles.

sin 0° = 0
sin 30° = 1/2
sin 45° = √2/2
sin 60° = √3/2
sin 90° = 1
cos 0° = 1
cos 30° = √3/2
cos 45° = √2/2
cos 60° = 1/2
cos 90° = 0
tan 0° = 0
tan 30° = √3/3
tan 45° = 1
tan 60° = √3

3. Trigonometric Identities

An identity is an equation that is true for all values for which both sides are defined.

Important Identity

sin²θ + cos²θ = 1

Other Useful Identities

tan θ = sin θ / cos θ
sec²θ = 1 + tan²θ
cosec²θ = 1 + cot²θ

Worked Example

Given sin θ = 3/5 and θ is acute, find cos θ.

sin²θ + cos²θ = 1
(3/5)² + cos²θ = 1
9/25 + cos²θ = 1
cos²θ = 16/25
cos θ = 4/5

4. Trigonometric Equations

When solving trigonometric equations, always pay attention to the specified range of θ.

Worked Example

Solve:

sin θ = 1/2

for 0° ≤ θ ≤ 360°.

θ = 30°

Sine is also positive in the second quadrant:

θ = 180° − 30°
θ = 150°
θ = 30°, 150°

5. The Sine Rule

The sine rule is useful when you know a side and its opposite angle, together with another side or angle.

a/sin A = b/sin B = c/sin C

Worked Example

Suppose:

A = 30°, B = 60°, a = 5

Find b.

5/sin30° = b/sin60°
b = 5(sin60°)/(sin30°)
b = 5√3

6. The Cosine Rule

The cosine rule is useful when you know two sides and the included angle, or all three sides.

a² = b² + c² − 2bc cos A

Worked Example

If b = 5, c = 7 and A = 60°, find a.

a² = 5² + 7² − 2(5)(7)cos60°
a² = 25 + 49 − 35
a² = 39
a = √39

7. Area of a Triangle

When two sides and the included angle are known:

Area = 1/2 ab sin C

Worked Example

Find the area of a triangle with sides 8 and 5 and included angle 30°.

Area = 1/2(8)(5)sin30°
= 20 × 1/2
= 10

⚠️ Common Mistakes

1. Calculator in the wrong mode

Check whether your calculator is in degrees or radians before solving trigonometric questions.

2. Missing solutions

When solving trigonometric equations, always consider the entire specified interval.

3. Choosing the wrong rule

Check whether the Sine Rule or Cosine Rule is appropriate before starting.

4. Forgetting the included angle

The area formula 1/2ab sin C requires the angle between the two known sides.

5. Rounding too early

Keep accurate values throughout your working and round only at the end if required.

🎯 Exam Tips

1. Check your calculator mode

Make sure you are using degrees or radians according to the question.

2. Draw a diagram

For triangle problems, a clear diagram can help identify opposite sides, included angles and the correct formula.

3. Write the formula first

Writing the formula before substituting values reduces the chance of using the wrong relationship.

4. Check all possible solutions

Trigonometric equations can have multiple solutions within the given interval.

5. Keep exact values when appropriate

If an exact answer is required, leave your answer in exact form rather than using a decimal approximation.
