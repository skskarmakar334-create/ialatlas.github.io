Mathematical Models in Mechanics

Learn how real-world mechanical situations are simplified into mathematical models.

What is a Mathematical Model?

A mathematical model is a simplified mathematical representation of a real physical situation.

In mechanics, models allow us to describe the motion and forces acting on objects using mathematics.

Key idea: A model is useful because it removes unnecessary complications while keeping the features that matter for solving the problem.

Common Modelling Assumptions

Mechanics questions often tell you, directly or indirectly, to make certain assumptions.

  • Particle: the object's size and shape are ignored.
  • Light string: the mass of the string is ignored.
  • Inextensible string: the string does not stretch.
  • Smooth surface: friction is ignored.
  • Rough surface: friction may act between surfaces.
  • Uniform object: mass is distributed evenly.
  • Rigid body: the shape does not change.
  • Gravity: acceleration due to gravity is usually taken as \(g = 9.8\,\text{m s}^{-2}\), unless the question specifies otherwise.

Why Assumptions Matter

Every assumption changes the mathematical model. You should therefore understand exactly what an assumption allows you to ignore.

Example: If a surface is described as smooth, there is no frictional force acting along the surface.

If the surface is rough, friction must be considered when appropriate.

Worked Examples

Example 1 — Identifying assumptions

A small object is modelled as a particle moving along a smooth horizontal surface. Explain what assumptions are being made.

Solution

The object is treated as a particle, so its size and shape are ignored.

The surface is smooth, so friction is ignored.

Example 2 — Light and inextensible string

Two particles are connected by a light, inextensible string. Explain what these two assumptions mean.

Solution

A light string has negligible mass.

An inextensible string does not stretch, so the distance between the connected particles remains fixed while the string is taut.

Practice Questions

Question 1

A car is modelled as a particle travelling along a straight road. State what is being ignored by treating the car as a particle.

Show answer

The size and shape of the car are ignored.

Question 2

A particle moves along a smooth surface. What force has been ignored because the surface is smooth?

Show answer

Friction has been ignored.

Question 3

A string is described as light and inextensible. State what each assumption means.

Show answer

Light means the string has negligible mass. Inextensible means the string does not stretch.

Common Mistakes

  • Forgetting that a smooth surface means friction is ignored.
  • Assuming every string is automatically inextensible.
  • Confusing a particle model with a rigid-body model.
  • Ignoring an assumption stated explicitly in the question.

Exam Tips

  • Read the modelling assumptions carefully before starting calculations.
  • Translate words such as smooth, light and inextensible into their mathematical consequences.
  • If asked to state an assumption, give a precise mechanical meaning.
  • Remember that the model is a simplification of reality.
