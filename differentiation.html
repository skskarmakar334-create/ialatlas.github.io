Differentiation

Edexcel International A Level Mathematics

1. What Is Differentiation?

Differentiation is the process of finding the derivative of a function.

The derivative tells us the rate at which one quantity changes with respect to another.

Geometrically, the derivative represents the gradient of a curve at a particular point.

dy/dx = gradient of the curve

2. The Power Rule

For a function of the form:

y = xⁿ

the derivative is:

dy/dx = nxⁿ⁻¹

Worked Example

Differentiate:

y = x⁵
dy/dx = 5x⁴

Therefore:

dy/dx = 5x⁴

3. Differentiating Polynomials

Differentiate each term separately.

Constants differentiate to zero.

d/dx(c) = 0

Worked Example

Differentiate:

y = 4x³ + 5x² − 7x + 9
dy/dx = 12x² + 10x − 7

The constant 9 disappears because its derivative is zero.

4. Negative and Fractional Powers

Rewrite roots and fractions using indices before differentiating.

√x = x¹ᐟ²
1/x² = x⁻²

Worked Example

Differentiate:

y = √x
y = x¹ᐟ²
dy/dx = 1/2 x⁻¹ᐟ²
dy/dx = 1/(2√x)

5. Tangents and Normals

The gradient of a tangent is found using the derivative.

mₜ = dy/dx

The gradient of a normal is the negative reciprocal of the tangent gradient.

mₙ = −1/mₜ

Worked Example

Find the gradient of the tangent to:

y = x² + 3x

Differentiate:

dy/dx = 2x + 3

At x = 2:

mₜ = 2(2) + 3
= 7

Therefore the normal gradient is:

−1/7

6. Stationary Points

A stationary point occurs where the gradient of a curve is zero.

dy/dx = 0

Worked Example

Find the stationary points of:

y = x² − 4x + 3

Differentiate:

dy/dx = 2x − 4

Set the derivative equal to zero:

2x − 4 = 0
x = 2

Substitute x = 2 into the original equation:

y = 2² − 4(2) + 3
y = -1
Stationary point = (2, −1)

7. Second Derivative

The second derivative can help determine the nature of a stationary point.

d²y/dx²

If:

d²y/dx² > 0

the stationary point is a minimum.

If:

d²y/dx² < 0

the stationary point is a maximum.

Worked Example

For:

y = x² − 4x + 3

We have:

dy/dx = 2x − 4

Therefore:

d²y/dx² = 2

Since 2 is positive, the stationary point is a:

minimum

8. Increasing and Decreasing Functions

The sign of the first derivative tells us whether a function is increasing or decreasing.

dy/dx > 0 → increasing
dy/dx < 0 → decreasing

Stationary points occur where the derivative changes through zero.

9. Rates of Change

Differentiation can be used to describe how quickly one quantity changes with another.

Rate of change = dy/dx

Worked Example

The distance travelled by an object is:

s = t³ + 2t²

Its velocity is:

v = ds/dt
v = 3t² + 4t

Therefore, velocity is obtained by differentiating distance with respect to time.

⚠️ Common Mistakes

1. Forgetting to reduce the power

When differentiating xⁿ, multiply by n and then reduce the power by 1.

x⁵ → 5x⁴

2. Differentiating constants incorrectly

A constant differentiates to zero.

d/dx(7) = 0

3. Using the wrong sign for a normal

The normal gradient is the negative reciprocal of the tangent gradient.

4. Finding the y-coordinate incorrectly

After finding the x-coordinate of a stationary point, always substitute it into the original function to find y.

5. Confusing the first and second derivatives

The first derivative gives the gradient. The second derivative can be used to determine the nature of a stationary point.

🎯 Exam Tips

1. Rewrite before differentiating

Convert roots and fractions into powers when necessary.

2. Show your differentiation step

Clearly write the derivative before substituting values.

3. For stationary points, remember the full process

Differentiate → Set dy/dx = 0 → Find x → Find y

4. Check the question carefully

If the question asks for a tangent, normal, stationary point, maximum or minimum, make sure you answer exactly what is asked.

5. Keep exact values

Avoid unnecessary rounding unless the question requests a decimal answer.
