Coordinate Geometry

Pearson Edexcel International A Level Mathematics

1. Coordinate Geometry Basics

Coordinate geometry allows us to describe geometric shapes using algebra and coordinates.

Coordinates

A point is usually written as:

(x, y)

The x-coordinate describes the horizontal position, while the y-coordinate describes the vertical position.

Distance Between Two Points

For points (x₁, y₁) and (x₂, y₂), the distance is:

d = √[(x₂ − x₁)² + (y₂ − y₁)²]

Midpoint

The midpoint of two points is found by averaging their x-coordinates and y-coordinates.

M = ((x₁ + x₂)/2, (y₁ + y₂)/2)

2. Gradient of a Straight Line

The gradient describes the steepness of a straight line.

m = (y₂ − y₁) / (x₂ − x₁)

Equation of a Straight Line

y = mx + c

Here, m is the gradient and c is the y-intercept.

Worked Example

Find the gradient of the line passing through (2, 3) and (6, 11).

m = (11 − 3) / (6 − 2)
= 8 / 4
= 2

Therefore, the gradient is 2.

3. Equation of a Straight Line

A straight line can be written in the form:

y = mx + c

If you know the gradient and one point on the line, you can determine its equation.

Worked Example

Find the equation of the line with gradient 3 passing through (2, 7).

Start with:

y = 3x + c

Substitute the point (2, 7):

7 = 3(2) + c
7 = 6 + c
c = 1

Therefore:

y = 3x + 1

4. Parallel and Perpendicular Lines

Parallel Lines

Parallel lines have the same gradient.

m₁ = m₂

Perpendicular Lines

For two non-vertical perpendicular lines, the product of their gradients is -1.

m₁m₂ = -1

Worked Example

A line has gradient 2. Find the gradient of a perpendicular line.

2m = -1
m = -1/2

5. Equations and Intersections

Coordinate geometry can be used to find where lines and curves intersect.

Example

Consider the line:

y = x + 2

and the curve:

y = x²

At an intersection, both equations have the same value of y. Therefore:

x² = x + 2
x² − x − 2 = 0
(x − 2)(x + 1) = 0

Therefore:

x = 2 or x = -1

Substitute these values into either original equation to find the corresponding y-coordinates.

⚠️ Common Mistakes

1. Mixing up x and y coordinates

Remember that a coordinate is written as (x, y). The x-coordinate comes first.

2. Using the wrong order in the gradient formula

Keep the order consistent. If you subtract the y-values in one order, subtract the x-values in the same order.

3. Forgetting the negative reciprocal

The gradient of a perpendicular line is the negative reciprocal, not simply the reciprocal.

m = 2
perpendicular gradient = -1/2

4. Forgetting to find both coordinates

When finding an intersection, finding x alone is usually not enough if the question asks for the coordinates.

🎯 Exam Tips

1. Write the formula first

Writing the appropriate formula before substituting values can reduce calculation errors.

2. Keep your working organised

Coordinate geometry questions often involve several stages. Keep each stage clearly separated.

3. Check gradients carefully

For perpendicular lines, remember:

m₁m₂ = -1

4. Check your coordinates

If you calculate a midpoint, distance or intersection, check that the result makes sense from the original coordinates.

5. Give exact answers when appropriate

Keep exact values such as √5 unless the question specifically asks for a decimal approximation.
