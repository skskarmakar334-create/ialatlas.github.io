Sequences & Series

Edexcel International A Level Mathematics

1. Sequences

A sequence is an ordered list of numbers that follows a particular rule or pattern.

Example

3, 7, 11, 15, 19, ...

Each term increases by 4.

The number of a term in a sequence is represented by n.

2. Arithmetic Sequences

An arithmetic sequence has a constant difference between consecutive terms.

a, a + d, a + 2d, a + 3d, ...

The nth term is:

uₙ = a + (n − 1)d

where a is the first term and d is the common difference.

Worked Example

Find the nth term of:

5, 9, 13, 17, ...

First term:

a = 5

Common difference:

d = 4

Therefore:

uₙ = 5 + (n − 1)4
= 4n + 1

3. Geometric Sequences

A geometric sequence has a constant ratio between consecutive terms.

a, ar, ar², ar³, ...

The nth term is:

uₙ = arⁿ⁻¹

where a is the first term and r is the common ratio.

Worked Example

Find the nth term of:

3, 6, 12, 24, ...

First term:

a = 3

Common ratio:

r = 2

Therefore:

uₙ = 3 × 2ⁿ⁻¹

4. Sigma Notation

Sigma notation provides a compact way of writing the sum of several terms.

Σ

For example:

Σ⁵ₙ₌₁ n

means:

1 + 2 + 3 + 4 + 5

5. Arithmetic Series

The sum of the first n terms of an arithmetic sequence is:

Sₙ = n/2 [2a + (n − 1)d]

An alternative form is:

Sₙ = n/2 (a + l)

where l is the final term.

Worked Example

Find the sum of the first 10 terms of:

2, 5, 8, 11, ...

Here:

a = 2
d = 3
n = 10
S₁₀ = 10/2 [2(2) + 9(3)]
= 5(4 + 27)
= 155

6. Geometric Series

The sum of the first n terms of a geometric series is:

Sₙ = a(1 − rⁿ)/(1 − r)

provided r ≠ 1.

Worked Example

Find the sum of the first 5 terms of:

2 + 6 + 18 + 54 + ...
a = 2
r = 3
n = 5
S₅ = 2(1 − 3⁵)/(1 − 3)
= 242

⚠️ Common Mistakes

1. Confusing difference with ratio

Arithmetic sequences use a common difference, while geometric sequences use a common ratio.

2. Forgetting n − 1

The nth term of an arithmetic sequence is:

uₙ = a + (n − 1)d

Not a + nd.

3. Using the wrong formula

Make sure you identify whether the sequence is arithmetic or geometric before choosing a formula.

4. Sign errors

Be especially careful when the common difference or ratio is negative.

🎯 Exam Tips

1. Identify the sequence first

Check whether consecutive terms have a constant difference or a constant ratio.

2. Write down a, d, r and n

Before using a formula, identify the values you need.

3. Check the first term

After finding an nth-term formula, substitute n = 1 to make sure it gives the correct first term.

4. Check your final answer

For sums, estimate whether your answer is a sensible size compared with the individual terms.
