1. Algebraic Manipulation

Algebraic manipulation means changing an expression into an equivalent form while preserving its mathematical value.

Expanding

Multiply each term inside one bracket by every term inside the other bracket.

(a + b)(c + d) = ac + ad + bc + bd

Factorisation

Factorisation reverses expansion by expressing an algebraic expression as a product of simpler factors.

x² + 5x + 6 = (x + 2)(x + 3)

Worked Example

Expand and simplify:

(2x + 3)(x - 4)

Multiply each term:

2x(x) + 2x(-4) + 3(x) + 3(-4)
= 2x² - 8x + 3x - 12

Collect like terms:

2x² - 5x - 12

2. Indices and Surds

Indices and surds are essential algebraic tools in Edexcel IAL Mathematics. You should be comfortable working with positive, negative and fractional powers and expressing exact answers using surds.

Laws of Indices

aᵐ × aⁿ = aᵐ⁺ⁿ
aᵐ ÷ aⁿ = aᵐ⁻ⁿ
(aᵐ)ⁿ = aᵐⁿ

These laws apply to rational exponents as well as integer exponents, provided the expressions are defined.

Fractional Indices

a¹⁄ⁿ = ⁿ√a
aᵐ⁄ⁿ = ⁿ√(aᵐ)

Negative Indices

a⁻ⁿ = 1 / aⁿ

Surds

A surd is an exact irrational expression involving a root. Surds allow answers to remain exact rather than being rounded to decimal values.

√50 = √(25 × 2) = 5√2

Rationalising a Denominator

A denominator containing a surd can be rewritten so that the denominator is rational.

1 / √3 = √3 / 3

Worked Example

Simplify:

8³⁄²

Use the fractional index rule:

8³⁄² = (√8)³

Since √8 = 2√2:

(2√2)³
= 8(√2)³
= 16√2

Therefore:

8³⁄² = 16√2

Surd Example

Simplify:

√72
√72 = √(36 × 2)
= 6√2

Therefore:

√72 = 6√2

3. Quadratic Equations

A quadratic equation can be written in the form ax² + bx + c = 0, where a ≠ 0. Quadratics are an important part of Edexcel IAL Mathematics.

Solving by Factorisation

When possible, factorise the quadratic and use the zero-product principle.

x² + 5x + 6 = 0

Factorise:

(x + 2)(x + 3) = 0

Therefore:

x = -2   or   x = -3

The Quadratic Formula

x = (-b ± √(b² - 4ac)) / 2a

The quadratic formula can be used when factorisation is difficult or impossible.

The Discriminant

Δ = b² - 4ac

The discriminant tells us how many real roots a quadratic equation has.

Δ > 0 → two distinct real roots

Δ = 0 → one repeated real root

Δ < 0 → no real roots

Completing the Square

Completing the square rewrites a quadratic into a form that makes its structure easier to analyse.

x² + 6x + 5 = (x + 3)² - 4

This form can help identify the coordinates of the turning point and determine the minimum or maximum value of a quadratic.

Worked Example

Solve:

2x² - 7x + 3 = 0

Factorise:

(2x - 1)(x - 3) = 0

Therefore either:

2x - 1 = 0
x = 1/2

or:

x - 3 = 0
x = 3

Therefore:

x = 1/2 or x = 3

Discriminant Example

Determine the number of real roots:

x² + 4x + 7 = 0
Δ = b² - 4ac
= 4² - 4(1)(7)
= -12

Since Δ < 0, the equation has:

No real roots

4. Simultaneous Equations

Simultaneous equations are equations that must be satisfied at the same time. They can be solved using substitution or elimination.

Example

2x + y = 7
x - y = 2

From the second equation:

y = x - 2

Substitute this into the first equation:

2x + (x - 2) = 7
3x = 9
x = 3

Therefore:

y = 1

5. Inequalities

Inequalities compare quantities using symbols such as <, >, ≤ and ≥.

Important Rule

When multiplying or dividing an inequality by a negative number, the inequality sign reverses.

-2x > 6

x < -3

Quadratic Inequalities

For quadratic inequalities, first find the roots and then determine which intervals satisfy the inequality.

x² - 5x + 6 > 0

(x - 2)(x - 3) > 0

The solution is:

x < 2   or   x > 3

Worked Example

Solve simultaneously:

2x + y = 11
x - y = 1

From the second equation:

y = x - 1

Substitute into the first equation:

2x + (x - 1) = 11
3x = 12
x = 4

Substitute x = 4:

y = 4 - 1
y = 3

Therefore:

x = 4,   y = 3

Worked Example

Solve:

3x - 5 > 7

Add 5 to both sides:

3x > 12

Divide by 3:

x > 4

Quadratic Inequality Example

Solve:

x² - 5x + 6 > 0

Factorise:

(x - 2)(x - 3) > 0

The quadratic is positive outside its two roots.

x < 2   or   x > 3

6. Functions

A function is a rule that maps each allowed input to exactly one output. Functions are usually written using notation such as f(x).

Function Notation

f(x) = 2x + 3

To find f(4), substitute x = 4:

f(4) = 2(4) + 3 = 11

Domain and Range

The domain is the set of permitted input values. The range is the set of possible output values.

When working with functions, always pay attention to restrictions placed on the domain.

Composite Functions

A composite function applies one function to the output of another.

(fg)(x) = f(g(x))

For example, let:

f(x) = 2x + 1
g(x) = x²

Then:

(fg)(x) = f(g(x))
= 2x² + 1

Inverse Functions

An inverse function reverses the mapping of a function. The inverse of f is written as f⁻¹.

f(f⁻¹(x)) = x
f⁻¹(f(x)) = x

Finding an Inverse

Suppose:

f(x) = 3x + 2

Write y = 3x + 2, interchange x and y, then rearrange:

x = 3y + 2

y = (x - 2) / 3

Therefore:

f⁻¹(x) = (x - 2) / 3

Worked Example

Let

f(x) = 2x + 3
g(x) = x²

Find (fg)(2).

First calculate g(2):

g(2) = 2² = 4

Now substitute this result into f:

f(g(2)) = f(4)
= 2(4) + 3
= 11

Therefore:

(fg)(2) = 11
