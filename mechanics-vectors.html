LESSON 01

What is a Vector?

A vector is a quantity that has both magnitude and direction.

Examples of vector quantities:

Displacement, velocity, acceleration and force.

Scalar quantities have magnitude only. Examples include distance, speed, mass and time.

LESSON 02

Representing Vectors

A vector can be represented using a directed line segment. The arrow shows its direction and the length represents its magnitude.

Key idea:

Same magnitude + same direction = same vector.

LESSON 03

Column Vectors

In two dimensions, vectors can be written as column vectors.

a = ( x , y )

The first component represents the horizontal direction and the second component represents the vertical direction.

LESSON 04

Magnitude of a Vector

For a vector with horizontal component x and vertical component y, its magnitude is found using Pythagoras.

|a| = √(x² + y²)

Example

Find the magnitude of the vector (3, 4).

|a| = √(3² + 4²)

|a| = √25

|a| = 5

LESSON 05

Adding and Subtracting Vectors

Vectors can be added by adding their corresponding components.

(a, b) + (c, d) = (a + c, b + d)

Similarly, subtraction is performed component by component.

(a, b) − (c, d) = (a − c, b − d)

LESSON 06

Scalar Multiplication

Multiplying a vector by a scalar changes its magnitude. A negative scalar also reverses its direction.

k(a, b) = (ka, kb)

LESSON 07

Vectors in Mechanics

Vectors are used throughout mechanics to describe physical quantities such as displacement, velocity, acceleration and force.

  • Displacement has magnitude and direction.
  • Velocity has magnitude and direction.
  • Acceleration has magnitude and direction.
  • Force has magnitude and direction.
